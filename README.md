# Elechid 音立

香港影音及智能家居店。Elechid 音立製作免費的中英文開源工具，讓你在選購電視或 CCTV 前，先按家居空間和錄影需要計算。

Elechid is a Hong Kong retailer specialising in audiovisual and smart home products. We publish free, bilingual, open-source tools to help shoppers plan a TV setup or estimate CCTV storage before buying.
