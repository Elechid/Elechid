# Elechid 音立

香港影音及智能家居店。Elechid 音立製作免費的中英文開源工具，讓你在選購電視、Soundbar、CCTV 或智能門鎖前，核對尺寸、送裝收費、錄影用量及配件相容性。

Elechid is a Hong Kong retailer specialising in audiovisual and smart home products. We publish free, bilingual, open-source tools for TV sizing and delivery, Soundbar setup and accessories, CCTV storage and compatibility, and smart door measurements.
